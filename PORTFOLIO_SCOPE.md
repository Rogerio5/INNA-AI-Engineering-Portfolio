# INNA AI Engineering Portfolio — Public Scope

## Objetivo

Este repositório demonstra competências práticas de Engenharia de IA
utilizando educação financeira como domínio de aplicação.

## Incluído

### Semana 1
- agentes de IA
- LangGraph
- Context Engineering
- Tool Use
- Structured Outputs
- Gemini

### Semana 2
- arquitetura multiagente
- supervisão
- handoffs
- persistência de estado
- checkpoints
- Human-in-the-Loop
- Phoenix
- OpenTelemetry
- avaliação automatizada

### Semana 3
- RAG
- Hybrid Retrieval
- embeddings
- pgvector
- RRF
- reranking
- Sentence-Window Retrieval
- Auto-Merging Retrieval
- Knowledge Graph
- Neo4j
- GraphRAG
- DeepEval
- RAG Triad
- Quality Gates

### Semana 4
- Agentic RAG
- Router Agents
- Research Agents
- Tool Calling
- LlamaIndex AgentWorkflow
- RAGAS
- TruLens
- DeepEval
- CI/CD de avaliação

## Domínio demonstrativo

Educação financeira é utilizada como caso de uso para demonstrar
arquiteturas e práticas de Engenharia de Inteligência Artificial.

## Fora do escopo público

A versão comercial e completa da plataforma financeira permanece
separada deste repositório.

Não fazem parte deste portfólio:

- tenants;
- assinaturas;
- billing;
- faturamento;
- planos comerciais;
- crédito como produto;
- patrimônio;
- administração comercial;
- integrações comerciais;
- regras proprietárias da Sabino.AI;
- dados de clientes;
- segredos e credenciais.
