# Public Boundary

Este repositório é uma implementação pública de portfólio.

## Incluído

- agentes e multiagentes;
- LangGraph;
- Context Engineering;
- Tool Calling;
- RAG híbrido;
- Agentic RAG;
- GraphRAG;
- memória;
- HITL;
- MCP;
- A2A;
- avaliação;
- observabilidade;
- resiliência.

## Não incluído

- dados reais de clientes;
- tenants comerciais;
- billing;
- planos;
- assinaturas;
- credenciais;
- dados financeiros privados;
- envio real de e-mail;
- envio real de Telegram;
- regras proprietárias completas da Sabino.AI.

## Dados

Exemplos e testes devem utilizar apenas dados fictícios ou sintéticos.
